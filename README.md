# MathQuest – Adaptive Sinhala Mathematics Game for ADHD-Related Learning Support

MathQuest is a research-based web application designed to provide adaptive mathematics learning support for Sri Lankan children aged 6–10 with ADHD-related learning needs.

The system provides a personalized and attention-friendly learning experience by combining learner profiling, adaptive content, gameplay behaviour analysis, and intelligent learning progression.

The platform primarily supports Sinhala-medium learners and follows the Sri Lankan primary mathematics curriculum.

## Main Components

- Learner Profile and Prediction Engine
- Attention-Friendly Content Adaptation Engine
- Gameplay Interaction and Behaviour Signal Engine
- Intelligent Pedagogical Agent and Adaptive Progress Engine

## Target Users

- Children aged 6–10
- Parents / Guardians
- Teachers

> MathQuest is intended for educational and research purposes and is not designed to diagnose ADHD.
