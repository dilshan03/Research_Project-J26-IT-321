# 4. Proposed Sinhala Instructions (with English translations)

> **UNVERIFIED DRAFT WORDING.** The Sinhala below was written by the research team for spoken, everyday
> (colloquial) Sinhala suitable for 6-year-olds. It **must** be checked by a native Sinhala speaker **and** a
> Sinhala-medium Grade 1 teacher before any use. The English column is the team's own translation for checking
> meaning; it is not a certified back-translation.
>
> Many Grade 1 children may not read fluently. The draft assumes every instruction is **spoken aloud** (audio) and also
> shown as text. Whether a suitable Sinhala voice is available on children's devices is still open.

**Verification columns (please fill in):**
- **NS** = native-speaker check (✓ natural / ✗ needs change, plus a correction).
- **ED** = educator check (✓ suitable for Grade 1 / ✗ unsuitable, plus a comment).

## 4.6 Teaching script (guided questions; every child)
Each level appears only after an incorrect try. The examples use the actual teaching item **Q3 (balls: 4 / 6 / 3)**.

| Level | Proposed Sinhala | English (team translation) | What appears on screen (draft) | NS | ED |
|---|---|---|---|---|---|
| Intro | දැන් අපි එකට බලමු. වැඩිම බෝල තියෙන්නේ කොයි කොටුවේද? | Now let's look together. Which box has the most balls? | The three boxes | | |
| **L1 clarify** | අපි හැම කොටුවකම බෝල එකින් එක ගණන් කරමු. | Let's count the balls in each box, one by one. | The instruction only | | |
| **L2 visual cue** | බලන්න, හැම බෝලයකටම අංකයක් තියෙනවා. ලොකුම අංකය තියෙන කොටුව මොකක්ද? | Look, every ball has a number. Which box has the biggest number? | Number tags (1, 2, 3, …) appear on the objects in each box | | |
| **L3 worked demonstration** | බලන්න: මේ කොටුවේ බෝල හතරයි, මේකේ හයයි, මේකේ තුනයි. හය තමයි වැඩිම. ඒ නිසා වැඩිම බෝල තියෙන්නේ මේ කොටුවේ. | Look: this box has four balls, this one six, this one three. Six is the most. So the most balls are in this box. | Each box highlighted in turn with its total; the correct box is then highlighted | | |
| Try again (after incorrect, before the next level) | ආයෙත් එකට බලමු. | Let's look again together. | — | | |
| After a correct teaching answer | ඔව්! වැඩිම බෝල තියෙන්නේ මේ කොටුවේ. | Yes! This box has the most balls. | Correct box highlighted | | |

**Educator questions about the script (also in form 5):**
- Is counting each box the strategy you want to teach, or should the teaching model one-to-one matching or estimation?
- Should L3 say the numbers as words (හය) or show digits?
- In the earlier two-group design, L2 drew pairing lines between groups. With three groups this is harder to show,
  so the draft uses number tags instead. Is that suitable?
