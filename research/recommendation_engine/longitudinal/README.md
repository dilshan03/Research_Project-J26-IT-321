# Longitudinal Progress & Questionnaire Monitoring (`longitudinal/`)

## Purpose
This directory stores research methodologies, longitudinal trajectory models, and analysis tools for tracking educational progress and questionnaire-indicator patterns across multiple gameplay sessions.

## Planned Scope
1. **Mathematics Learning Progress Tracking:**
   - Tracking skill estimate changes over time (e.g., transition from Emerging $\rightarrow$ Developing $\rightarrow$ Proficient).
   - Measuring stability, retention, and rate of decay across spaced learning intervals.
2. **Questionnaire Indicator Trajectories:**
   - Tracking longitudinal caregiver/teacher observations (e.g., repeated SNAP-IV subscale indicators over multi-week research pilot windows).
   - Examining correlations between observed inattention/hyperactivity indicators and mathematical task completion persistence.
3. **Trend Analysis & Safeguards:**
   - Statistical distinction between genuine developmental learning growth and natural day-to-day session variance (e.g., fatigue, hunger, environment).
