# Machine Learning Experiments (`ml_experiments/`)

## Purpose
This directory houses offline experimental pipelines for supervised machine learning, prediction targets (IMPSA and IMLR), supervised ADHD presentation classification research, and Explainable AI (XAI) using SHAP.

## Planned Scope
1. **Prediction Targets Research:**
   - **IMPSA (Independent Mathematical Problem-Solving Ability):** Investigating feature sets (unassisted first-response correctness, response latency distributions, attempt frequencies) for predicting independent problem-solving capacity.
   - **IMLR (Independent Mathematical Learning Readiness):** Dynamic assessment transfer modeling based on pre-probe $\rightarrow$ scaffolding $\rightarrow$ post-transfer performance.
2. **Supervised ADHD Presentation Classification Research:**
   - Offline research exploring supervised classification of ADHD presentation subtypes (Inattentive, Hyperactive-Impulsive, Combined).
   - **Prerequisite Boundary:** This research will be conducted **strictly offline and only if and when clinically established reference labels with formal ethical approvals** are available.
3. **Explainable AI (XAI) & SHAP:**
   - Feature attribution using SHAP (SHapley Additive exPlanations) to explain model predictions to parents and educators without "black-box" opacity.
4. **Model Comparison & Benchmarks:**
   - Empirical comparisons across candidate algorithms (Logistic Regression, Decision Trees, Random Forests, XGBoost).

## Implemented: NSCH K2Q31A exploratory baseline (`nsch_baseline/`)

Supervised baseline predicting the NSCH survey outcome **K2Q31A** — a parent's report that a doctor or other
health care provider has *ever told* them their child (aged 6–10) has ADD/ADHD. Not a diagnostic model, not an
ADHD-presentation classifier, not a learning-readiness model, and not integrated into MathQuest.

| Document | Content |
| :--- | :--- |
| `NSCH_DATA_AUDIT.md` | Dataset inventory, labels, missing data, survey design, leakage audit |
| `NSCH_FEATURE_DICTIONARY.md` | Allowed (Tier A) and excluded variables |
| `NSCH_EXPERIMENT_PLAN.md` | Evaluation design |
| `NSCH_EXPERIMENT_REPORT.md` | Actual results (generated by `nsch_baseline.evaluate`) |

Run from this directory (environment: `.venv`, packages pinned in `requirements-nsch.lock.txt`):

```
.venv\Scripts\python.exe -m nsch_baseline.train                 # train on 2023-2024 only, select on validation, freeze
.venv\Scripts\python.exe -m nsch_baseline.evaluate              # evaluate the frozen model once on 2025, write report
.venv\Scripts\python.exe -m nsch_baseline.demo                  # prediction + verified SHAP for a held-out example
.venv\Scripts\python.exe -m nsch_baseline.demo --hypothetical examples\hypothetical_child.json
.venv\Scripts\python.exe -m unittest discover -s tests -t . -v  # verification tests
```

Raw data (`data/raw/`), the virtual environment and model binaries (`artifacts/**/*.joblib`, `*.npz`) are
git-ignored; metadata, metrics and the report are small text files.
